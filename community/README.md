# Notas de la comunidad / Community notes

Español · English below

Esta carpeta recoge **ideas, estrategias alternativas, experiencias y opiniones** de la comunidad que complementan el informe. A diferencia de los capítulos de `docs/`, aquí cada nota expresa el punto de vista de su autor, aunque debe seguir las mismas reglas de veracidad: citar fuentes y marcar las estimaciones.

**Cómo añadir una nota:**

1. Copiar [`TEMPLATE.md`](TEMPLATE.md) con el nombre `AAAA-MM-DD-tema-breve.md` (por ejemplo, `2026-11-10-incentivos-nodos-lectura.md`).
2. Rellenar la cabecera y el contenido. Puede estar en español, en inglés o en ambos.
3. Abrir un pull request. Si la nota propone cambiar el informe, enlazar el *issue* correspondiente.

Las notas que alcancen consenso pueden incorporarse después a los capítulos del informe.

This folder collects **ideas, alternative strategies, experiences and opinions** from the community that complement the report. Unlike the chapters in `docs/`, each note here expresses its author's point of view, but it must follow the same truthfulness rules: cite sources and mark estimates.

**How to add a note:**

1. Copy [`TEMPLATE.md`](TEMPLATE.md) as `YYYY-MM-DD-short-topic.md` (for example, `2026-11-10-read-node-incentives.md`).
2. Fill in the header and the content. It can be in Spanish, English or both.
3. Open a pull request. If the note proposes changing the report, link the related issue.

Notes that reach consensus can later be incorporated into the report's chapters.
